## Features

- Venue coinbase / BTC-USD
- Strategy id dca
- Paper engine and stub candles
- Risk cap on notional / equity

## Prerequisites

- Go 1.22+
- Git

## Getting Started

```bash
git clone <repo-url>
cd coinbase-adv-bot
make build
./bin/cbadv -help
```

## CLI Usage

```bash
make test
go run ./cmd/cbadv -help
```
